# Dronefly bot

Dronefly is a bot for naturalists that gives users access to
[iNaturalist](https://www.inaturalist.org) on [Discord](https://discord.com)
chat.

## Documentation

- [Dronefly Bot Wiki](https://github.com/dronefly-garden/dronefly/wiki)
- [Dronefly Project Documentation](https://dronefly.readthedocs.io/)
